# NovelShell 2.0
A simple, clean, minimal shell for Hyprland + Arch Linux, that just works.

### Demo
https://github.com/user-attachments/assets/d6f8354b-5297-4899-a939-cda5b90fa8a8



### Quick Start(Only for Arch + Hyprland):
1. Get the installer file from [releases](https://github.com/readsack/NovelShell2/releases/tag/alpha)

2. Make the file an executable & run the file.

3. Enter the system password if asked (required to install necessary packages)

4. If everything works correctly, you should see a bar at the top of your screen  

5. If everything is running smoothly, you might want to add the ```qs``` command as autolaunch to your Hyprland config (if you want to keep using the shell)
